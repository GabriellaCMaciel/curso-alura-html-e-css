Tags HTML

O que são tags HTML?

As tags HTML são elementos que definem a estrutura e o conteúdo de uma página web. Elas são usadas para marcar diferentes partes do conteúdo, como títulos, parágrafos, links, imagens e muito mais.

Exemplos de tags HTML

  • <h1> - Título principal
  • <p> - Parágrafo
  • <a> - Link
  • <img> - Imagem
